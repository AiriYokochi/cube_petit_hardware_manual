## LiDARの動作確認

LiDARをとPCは図のようにつながっています。

端末で以下のコマンドを叩きます。
```
ros2 launch cube_petit_bringup lidar_check.launch.py
```
画面が出てくるので、LiDARの赤い点が出ていることを確認してください。
確認したら**Ctrl**を押しながら**D**を押して終了します。

#### 動かないとき
LiDARが赤く光っていることを確認してください。
