## 搭載PCの選定について

---
入るサイズであればどのminiPCでもRaspberryPi4,5でも大丈夫ですが、<br>
スペックが低いと**動作が重い**、一定の機能が使えないなどの制限があります。<br>
スペックが高すぎると**バッテリーの持ちが悪くなる**、落ちるといった問題があります。<br>
丁度いいスペックのPCで購入可能なものを探していただけると助かります。<br>

**おすすめの機能**<br>

- サイズは幅12[cm]程度
- 電源を安定させたいならDCジャック、PDでも省電力(TDP15W~25W)のものを
- インターフェース
    - USB type A (3.0)が2個以上
    - HDMI
    - Bluetooth (コントローラとの接続)
    - Wifi (必須)
- CPUスペック
　- AMD Ryzen 7 6800U以下くらいで動きます。
　- GPUはいらないです
- RAM 32GB, SSD 512GB以上

**動作確認済みPC**<br>

- MINIFORUM EM680(2023/4) 参考価格７万円程度
- MINIFORUM S100(2024/4) 参考価格3万円程度(※リアルタイム会話機能が制限されます)
