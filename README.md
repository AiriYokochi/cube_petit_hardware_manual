# cube_petit_hardware_manual

This is Hardware Assembly Manual for Cube petit v3


## Install

https://www.mkdocs.org/getting-started/

```
sudo apt install -y python3-pymdownx
pip install mkdocs
git clone https://github.com/AiriYokochi/cube_petit_hardware_manual.git
cd cube_petit_hardware_manual
mkdocs build
mkdocs serve --dev-addr=0.0.0.0:8000
```

access http://127.0.0.1:8000/
